Import from CSV

Export the registrations from the Google Sheet (File → Download → CSV) and choose the file here. Only rows with a payment date are imported, numbered in payment order (#1 = paid first). The file is read only in this browser – only team and player names are saved.

If both names are in one column (e.g. “Ali, Umer”), choose it for Player 1 and leave Player 2 empty – the names are split automatically.

If the form asks once for both players, choose that column above and leave Player 2 empty.

Save to GitHub

Results are saved straight into the website's GitHub repository. The token is stored only in this browser – every admin sets it up once on their own device.

How to create the token
  1. GitHub → your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Resource owner: the account that owns the website. Repository access: Only select repositories → the website repository.
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  4. Set an expiry date (e.g. end of the season), generate, and paste it above.

Local test data

Without a GitHub connection, saves stay in this browser only – handy for testing. To publish them by hand, download the files and upload them to the data/ folder on GitHub.
